# श्री बालाजी ज्योतिष केंद्र — Professional Website

## Mobile GitHub update
1. Download and extract this ZIP.
2. Open the GitHub repository and upload/replace the files in the repository root.
3. Keep `assets/icon.svg` inside an `assets` folder at repository root.
4. Commit changes and wait for GitHub Pages to redeploy.
5. Open the live site and refresh it.

## Required setup
- Open `app.js` and replace `YOUR_WHATSAPP_NUMBER` with the actual WhatsApp number using digits only (India example: `919876543210`).
- Replace sample gemstone artwork with actual product photos and accurate inventory, prices, weights and lab-report details before selling.
- Do not claim that stones are natural/certified unless supported by valid evidence.
- The form opens WhatsApp; it does not store bookings or accept payments.

## Publish
GitHub Pages settings: Source = Deploy from a branch; Branch = `main`; folder = `/(root)`.
This is a static website and installable PWA, not a native Android APK. No online payment gateway, server-side booking, inventory admin or customer accounts are included.
